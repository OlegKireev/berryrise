# Морс

Android-приложение для отказа от алкоголя (Expo, React Native). Продуктовая спека - [docs/idea.md](docs/idea.md), устройство кода - [CLAUDE.md](CLAUDE.md).

## Версии приложения

| Версия                     | Что это                                                                               | Когда                                                                |
| -------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **dev**                    | dev build с `expo-dev-client`: JS грузится с metro (`yarn start`), правки видны сразу | разработка                                                           |
| **preview**                | полноценный APK, JS внутри, metro не нужен                                            | пользоваться как обычным приложением, проверить "как у пользователя" |
| **debug** (`yarn android`) | локальная debug-сборка, подписана debug-ключом                                        | только эмулятор                                                      |

- dev и preview - разные приложения: preview - `com.berryrise.app` ("Морс"), dev - `com.berryrise.app.dev` ("Морс dev", scheme `berryrise-dev`). На телефоне стоят рядом, данные у каждого свои; перенести можно экспортом и импортом. Разницу задает `app.config.ts` по `APP_VARIANT` из профиля `development` в `eas.json`.
- Ключ подписи в EAS привязан к пакету. Первую сборку нового пакета запускай интерактивно (или сначала `yarn eas credentials`), чтобы EAS сгенерировал keystore; дальше сборки берут его сами.
- Локальная и облачная сборка одного профиля подписаны одним ключом из EAS и ставятся поверх друг друга.
- debug подписан другим ключом: поверх dev/preview не встанет, только через удаление приложения, а с ним удалятся данные. Поэтому на телефон debug не ставим.
- Пересобирать нужно только после нативных изменений: пакеты с нативным кодом, `app.json`, `app.config.ts`, `eas.json`. Правки JS/TS подхватывает metro в dev-версии.

## Подготовка (один раз)

1. Node 24, `yarn install` (yarn 4).
2. JDK 17: `brew install openjdk@17`. JDK 25 из Android Studio сборку ломает.
3. Android Studio - ставит Android SDK и эмулятор.
4. В `~/.zshrc`:
   ```bash
   export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
   export ANDROID_HOME=$HOME/Library/Android/sdk
   export PATH=$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH
   ```
5. Вход в EAS (нужен и для локальных сборок - оттуда берется ключ подписи): `yarn eas login`.

## Свой телефон

### Подготовка телефона (один раз)

1. "О телефоне" → 7 раз тапнуть по версии прошивки (на Xiaomi - "Версия ОС") → появится "Для разработчиков".
2. "Для разработчиков":
   - "Отладка по USB";
   - "Установка через USB" - без нее установка через adb висит на `Performing Streamed Install`, в том числе по Wi-Fi;
   - на Xiaomi еще "Отладка по USB (настройки безопасности)" - нужен вход в Mi-аккаунт.

### Подключение

По кабелю: подключить, на телефоне разрешить отладку, проверить `adb devices`.

По Wi-Fi (Android 11+, телефон и мак в одной сети):

1. Один раз: "Для разработчиков" → "Отладка по Wi-Fi" → "Подключить устройство с помощью кода" → `adb pair <ip>:<порт>` и ввести код.
2. Каждый раз: на экране "Отладка по Wi-Fi" взять адрес и порт (они другие, чем при паринге) → `adb connect <ip>:<порт>` → `adb devices`.
   Порт меняется после перезагрузки или выключения отладки - тогда снова `adb connect`.

### Сборка и установка

```bash
yarn build:local:preview   # -> dist/berryrise-preview.apk, квоту EAS не тратит
yarn install:preview       # поставить на подключенный телефон
```

Для dev-версии - `yarn build:local:dev` и `yarn install:dev`, потом `yarn start` на маке. Приложение на телефоне подключится к metro по Wi-Fi (та же сеть) или по кабелю.

- Если подключено несколько устройств (телефон и эмулятор), указать телефон: `ANDROID_SERIAL=<ip:порт> yarn install:preview`.
- Локальная сборка идет в чистой временной папке, 6-10 минут.

## Эмулятор

1. Android Studio → Device Manager → новое устройство Pixel 8, образ **API 35 "Google APIs"** (без Play Store: с ним эмулятор зависает). В настройках устройства 4 ядра и 4 ГБ памяти.
2. Запустить эмулятор из Device Manager или `emulator -avd Pixel_8`.
3. `yarn android` - соберет debug, поставит и запустит metro. Первая сборка ~20 минут (докачивает NDK и SDK), дальше 1-2 минуты.

Для проверок из Claude Code есть скилл `emulator-check` (`.claude/skills/emulator-check/`): поднимает эмулятор и приложение, заводит тестовые данные, делает скриншоты.

## Сборка в облаке EAS

```bash
yarn build:eas:preview   # или build:eas:dev
```

- Тратит квоту: бесплатный тариф - 15 Android-сборок в месяц, очередь медленная. Нужна, когда собрать локально негде.
- По окончании EAS дает ссылку и QR-код: открыть на телефоне, скачать APK, установить (разрешить установку из браузера). Или скачать APK на мак и `adb install -r <файл>`.
- Ключ подписи тот же, что у локальных сборок: ставится поверх без потери данных.

## OTA-обновления

Preview и production-сборки при запуске проверяют EAS Update и качают новый JS-бандл в фоне, применяется он при следующем запуске. Бандл, упавший на старте, откатывается сам. Dev-сборка обновлений не получает.

Обновлением доставляется только JS и ассеты Metro. Нативное изменение (пакет с нативным кодом, плагин, нативные поля `app.json`) меняет `runtimeVersion` (политика `fingerprint`), и такой бандл до старых сборок не дойдет: нужна новая сборка. Миграции базы только аддитивные: после отката старый код должен работать на новой схеме.

```bash
yarn update:preview -m "fix: ..."   # публикация в канал preview
yarn update:promote                 # тот же бандл из preview в production (выбрать группу или --group <id>)
```

- Проверка: поставить preview-сборку, опубликовать, открыть приложение два раза. В "О приложении" рядом с версией появятся id и дата обновления, в журнале - запись `updates`.
- В production попадает только то, что было в preview: публикуем всегда в preview и промоутим.
- Откат: `yarn eas update:republish --group <id прошлой группы> --destination-channel <канал>`. Группы видно в `yarn eas update:list`.
- Обновления не подписаны: code signing в EAS Update есть только на платном тарифе. Кто получит доступ к аккаунту Expo, сможет выкатить свой код всем пользователям, поэтому на аккаунте обязательна 2FA.
- `update:preview` экспортирует бандл в `.expo/update`: `eas update` по умолчанию пишет в `dist/` и очищает ее вместе с APK.
