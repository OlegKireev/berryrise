# Проверка на эмуляторе

Все действия через один скрипт, без самописных adb-цепочек:

```bash
E() { python3 .claude/skills/emulator-check/scripts/emu.py "$@"; }   # zsh не делит $E на слова, нужна функция
export EMU_OUT=<scratchpad>/emu    # куда класть скриншоты и логи; по умолчанию $TMPDIR/sober-emu
```

Функцию и `EMU_OUT` объявляй в каждом вызове Bash: состояние шелла между вызовами не сохраняется.

## Порядок

1. `E up` - поднимает все, чего не хватает, и запускает приложение (холодный старт ~40 с, если все уже запущено - секунды):
   - эмулятор AVD `Pixel_8` (или `SOBER_AVD`), если устройства нет;
   - пересборка dev build, если APK нет или поменялись зависимости в `package.json` или содержимое `app.json`/`yarn.lock`/`eas.json` с прошлой сборки (хеш в `android/app/build/outputs/apk/debug/native-inputs.sha256`; `--build` - форсировать). Сборка локальная, квоту EAS не тратит, ~2 мин с кэшем. Правку скриптов `android`/`ios` в `package.json`, которую делает prebuild, скрипт откатывает;
   - установка APK, если приложения нет (`--install` - переставить);
   - язык приложения ru (`--locale en`);
   - metro на 8081: если пользователь уже держит `yarn start`, берет его;
   - запуск через deep link dev-клиента, закрытие приветствия dev-меню.
2. Данные - через `E seed`, а не проходя онбординг тапами (онбординг проверяй только если меняли его).
3. Сценарий: `E tap`, `E texts`, `E wait`, утверждения - по `E texts` (дешево), скриншот - только когда важен внешний вид.
4. `E down`: гасит только то, что запустил скрипт (эмулятор, metro), плюс Gradle daemon и adb-сервер. Чужой `yarn start` не трогает. Автоматически не гаси эмулятор, пока изменения не зафиксированы коммитом: между правками и ревью он нужен снова, а холодный старт долгий и иногда ловит ANR. Это исключение из общего правила "гасить процессы после работы". `E down` - после коммита или по просьбе пользователя.

JS-изменения metro подхватывает сам (Fast Refresh). Если экран не обновился - `E launch`.

## Команды

| Команда | Что делает |
| --- | --- |
| `up [--build] [--install] [--locale en]` | см. выше |
| `launch [--wait ТЕКСТ]` | перезапуск приложения с нуля, печатает тексты экрана |
| `texts` | все подписи на экране (text и content-desc) без повторов - главный способ "посмотреть" |
| `tap ТЕКСТ [--exact] [--nth N]` | тап по центру элемента, подпись которого содержит ТЕКСТ; ждет до 10 с; при промахе печатает экран |
| `tapxy X Y` | тап по координатам устройства (1080x2400), не скриншота |
| `wait ТЕКСТ [--timeout 15]` / `gone ТЕКСТ` | дождаться появления / убедиться, что пропало |
| `type ТЕКСТ` | ввод в поле в фокусе, только ASCII (цифры, латиница) |
| `key back\|enter\|hide` | системная "назад", Enter, скрыть клавиатуру |
| `scroll down\|up [--times N]` | прокрутка экрана |
| `shot ИМЯ [--full]` | скриншот 540x1200 (в 4 раза дешевле в контексте, текст читается), печатает путь для Read; `--full` - 1080x2400 |
| `seed ...` | заменяет данные (habit, срывы, причины, итоги, вечеринки) и перезапускает приложение, см. ниже |
| `sql "..."` | произвольный SQL на копии базы, база возвращается на устройство, приложение перезапускается |
| `query "SELECT ..."` | прочитать базу без изменений |
| `reset` | стереть данные приложения (`pm clear`): снова онбординг |
| `theme dark\|light` | системная тема |
| `locale ru\|en` | язык приложения, с перезапуском |
| `time "2026-10-14 17:59"` / `time auto` | сдвинуть часы эмулятора (нужен образ без Play Store: `adb root`); после - `launch` |
| `logs [--all]` | последние 80 строк logcat: JS, RN, падения |
| `notifs` | уведомления приложения в шторке и число запланированных алармов |
| `down` | уборка |

`seed`: `--days 60` (старт N дней назад в 21:00), `--relapses 4,20` (срывы N дней назад в 22:00), `--reasons health,sleep` (ключи из `entities/reason`), `--custom "своя причина"` (можно несколько раз, кириллица ок), `--spend 2100 --currency RUB`, `--drinks beer=14,wine=2`, `--reviews 0,1,2` (итоги дня N дней назад). База должна существовать: после `reset` сначала дай приложению стартовать (`launch` это делает).

## Как проверять эффективно

- Сначала `texts`, скриншот - только для внешнего вида (макет, темы, отступы). Тексты дают числа, порядок блоков и состояния без картинки.
- Ожидаемые числа считай заранее из seed: трезвых дней = дней от дня после старта до сегодня минус дни со срывом; деньги = `spend/7 * трезвые`, порции = `порций_в_неделю/7 * трезвые`.
- Обе темы: один скриншот в `theme dark`, потом верни `theme light`.
- Время: граница итогов дня - 18:00, смена дня - полночь. `time "... 17:59"`, `launch`, `texts`, потом `time "... 18:01"`. В конце `time auto`.
- Уведомления: включи вид в настройках, поставь время на пару минут вперед, сдвинь часы через `time`, смотри `notifs`.
- Каждую задачу "проверить на телефоне" из tasks.md закрывай после прохождения ее сценариев здесь и пиши, что именно проверено.

## Подводные камни

- Плавающая кнопка dev-клиента (шестеренка "Tools") лежит поверх приложения и перехватывает тапы. Если `tap` попал в нее (открылось меню с "Reload", "Go home") - `launch` его закроет; кнопку можно утащить: `adb shell input swipe <x> <y> <x2> <y2> 400`. В обычной сборке ее нет.
- Шестеренка настроек в шапке находится по тексту `⚙︎`.
- `adb input text` не вводит кириллицу - данные с русским текстом заводи через `seed`/`sql`.
- Эмулятор только с образом "Google APIs" без Play Store, 4 ядра и 4 ГБ (`~/.android/avd/<AVD>.avd/config.ini`). Образ Android 17 с Play Store зависал целиком (`system_server`, ANR у системных приложений).
- Сборке нужен JDK 17 (`brew install openjdk@17`): JDK 25 из Android Studio валит CMake-шаг. Скрипт подставляет JDK 17 сам.
- Пока идет первая сборка, эмулятор тормозит; после сборки скрипт гасит Gradle daemon.
- Если `up` пишет "эмулятор не загрузился" или adb висит: `adb emu kill`, потом `E up`.
- Данные эмулятора - тестовые, их можно сбрасывать. Реальный телефон пользователя этим скриптом не трогай.
