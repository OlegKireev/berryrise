# Spec Delta

## MODIFIED Requirements

### Requirement: Приложение недоступно до онбординга

Пока онбординг не завершен, система SHALL открывать приложение на первом шаге онбординга и MUST NOT показывать табы. Онбординг считается завершенным после подтверждения старта или после восстановления из файла, в котором есть старт; шаги после старта необязательные. После завершения онбординг SHALL больше не показываться.

#### Scenario: Первый запуск

- **WHEN** пользователь впервые открывает приложение
- **THEN** открывается первый шаг онбординга, табы недоступны

#### Scenario: Онбординг прерван

- **WHEN** пользователь закрыл приложение, не подтвердив старт, и открыл снова
- **THEN** онбординг начинается с первого шага

#### Scenario: Онбординг прерван после старта

- **WHEN** пользователь подтвердил старт, закрыл приложение на шаге причин и открыл снова
- **THEN** открывается таб "Сегодня", шаг причин больше не показывается

#### Scenario: Онбординг пройден

- **WHEN** пользователь завершил онбординг и перезапустил приложение
- **THEN** открывается таб "Сегодня"

#### Scenario: Восстановлен из файла и перезапущен

- **WHEN** пользователь восстановил данные из файла на первом шаге и перезапустил приложение
- **THEN** открывается таб "Сегодня"

## ADDED Requirements

### Requirement: Восстановление из файла в онбординге

Первый шаг онбординга SHALL содержать тихую ссылку "Восстановить из файла" под основной кнопкой. Она запускает импорт (требования `backup`) без подтверждения замены: на этом шаге заменять нечего. Если в файле есть неудаленный старт, онбординг SHALL завершаться и открываться "Сегодня". Если старта нет, данные из файла применяются, а пользователь SHALL оставаться на первом шаге с сообщением, что в копии нет старта.

#### Scenario: Восстановление на новом телефоне

- **WHEN** пользователь на первом шаге нажал "Восстановить из файла" и выбрал свой экспорт со стриком 40 дней
- **THEN** открывается "Сегодня" со стриком 40 дней, дисклеймер и скрининг не показываются

#### Scenario: В копии нет старта

- **WHEN** пользователь выбрал корректный файл, в котором нет старта
- **THEN** остается на первом шаге и видит сообщение, что в копии нет старта и онбординг нужно пройти

#### Scenario: Неподходящий файл

- **WHEN** пользователь выбрал чужой файл
- **THEN** видит сообщение, что это не резервная копия "Решено", и остается на первом шаге
