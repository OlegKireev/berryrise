# Design

## Context

Все данные уже есть: `dayReview` (одни итоги на день, `date` строкой `YYYY-MM-DD`, ответы ключами из `shared/config/options.ts`, списки JSON-массивами), `relapse` (`at` в ms, `places`/`hardships` JSON или NULL), `party` (`startAt`, `result`). Схема не меняется.

На "Прогрессе" уже есть похожие куски: `PeriodNav` (подпись и стрелки, общий для календаря и модалки дня), `useCalendar` с границами листания по `monthIndex`, отдельный экран стека "Все достижения" на роуте из одной строки. Запросы по диапазону: `listRelapsesBetween(db, from, to)` уже есть, для итогов и вечеринок нужны свои.

Требования - в `specs/insights/spec.md`.

## Goals / Non-Goals

**Goals:**

- Вся арифметика (периоды, средние, топы, порог) - чистые функции с тестом.
- Экран и превью считаются одной функцией, превью - тот же расчет за "Последние 30 дней".

**Non-Goals:**

- Кэш или предрасчет агрегатов: период - максимум 31 строка итогов и несколько срывов и вечеринок, считаем на лету при каждом фокусе.
- Анимации графиков.

## Decisions

### Слайс: всё в `pages/progress`

Превью лежит на `ProgressPage`, а слайсы одного слоя друг друга не импортируют. Отдельный `pages/insights` заставил бы выносить логику в `features` без причины (действия пользователя тут нет). Поэтому `InsightsPage`, секция `InsightsPreview`, хук и логика - в `pages/progress`, как `AchievementsPage`. Роут `src/app/insights.tsx` - одна строка реэкспорта, экран регистрируется в корневом `Stack` с заголовком `t('insights')` из `common.ts` ("Статистика" / "Insights").

### Период - значение, а не индекс месяца

```
type Period = { kind: 'last30' } | { kind: 'month'; year; month }
```

Чистые функции в `model/insights.ts`:

- `periodDays(period, now)` - список дат `YYYY-MM-DD` периода по порядку (`last30` - сегодня и 29 дней до него, `month` - все дни месяца). Из него берутся границы `[first, last]` для SQL и ряд дней для настроения.
- Листание: список доступных периодов `[last30, прошлый месяц, ..., месяц старта]`, хук держит индекс в нем. Месяцы - от `monthIndex(now) - 1` вниз до `monthIndex(startAt)`. Если старт в текущем месяце, список из одного `last30`. `monthIndex` переиспользуем из `model/calendar.ts`.
- Подпись: `last30` - строка словаря, месяц - `formatMonth` (год только не текущий), как в календаре.

Альтернатива - хранить в хуке индекс месяца и отдельный флаг "скользящее окно": больше ветвлений в листании, список проще.

### Агрегация одной функцией

`insights({ reviews, relapses, partyResults })` → объект для экрана:

- `reviewCount` и `enough = reviewCount >= 7`;
- `cravingByWeekday`: 7 значений с понедельника, среднее по уровню (индекс в `cravings`: 0..3) или `null`, если итогов за этот день недели нет. День недели - из строки даты через локальный `Date(y, m - 1, d)`, без часовых поясов;
- `moodCounts`: сколько итогов с каждым настроением 1..5;
- `hardships`, `helpers`: `top3(lists, order, exclude)` - счет по вхождениям, без `nothing`/`notNeeded`, стабильная сортировка по счету, при равенстве - порядок массива в `options.ts`, ненулевые, первые 3;
- `relapses`: `null` без срывов, иначе `{ count, hardships, places }` теми же `top3` (у срыва `NULL` в поле = пустой список);
- `company`: `null` без вечеров с `result`, иначе `{ total, sober }`.

Превью берет из того же объекта день с максимальным `cravingByWeekday` (при равенстве - ранний в неделе; если максимум 0 - "тяги не было") и первый из `helpers` (нет - строку не показываем).

Тест рядом (`insights.test.ts`): границы периодов, переход на летнее время в `last30` (TZ=Europe/Berlin в `yarn test`), список периодов при старте в текущем и прошлом месяце, среднее и пустой день недели, топ с равенствами и исключениями, срывы без разбора, порог.

### Запросы

- `day-review`: `listDayReviewsBetween(db, fromDate, toDate)` по `date >= ? AND date <= ?` (строки сравниваются лексикографически), строки как есть; JSON-списки итогов и срывов парсит `useInsights`, как `useDayCard`.
- `relapse`: существующий `listRelapsesBetween` с границами из `dayRange(first).from` и `dayRange(last).to`.
- `party`: `listPartyResultsBetween(db, from, to)` - `result` неудаленных вечеринок с `result IS NOT NULL` и началом в `[from, to)`.

Хук `useInsights(period)` в `model/` грузит все три на `useFocusEffect` и при смене периода, возвращает `null` до первой загрузки; при смене периода показываем прежние данные до прихода новых, как в модалке дня. Превью зовет его со своим `last30` (секция со своими данными - свой хук, как `RepliesSection`).

### Рисование без SVG

Графики на `View` и токенах темы, новых токенов нет:

```
Тяга по дням недели          Настроение
Сильно  -------#---------    [####|########|###|#   ]
Заметно -------#---------     Отлично 4  Хорошо 6
Слегка  -#-----#-#-------     Нормально 2  Плохо 1
Нет     -#--.--#-#-------
          Пн Вт Ср Чт Пт

Что было сложным
 стресс       ##########  9
 усталость    #####       5
```

- Тяга: шкала слева с подписями уровней (`option.craving.*`) и линии сетки на их высоте, 7 колонок, высота столбика = среднее / 3, день без данных - без столбика. Тяга "нет" (0) - тонкая линия у основания, чтобы отличалась от пустого дня. Без шкалы высота столбика не читалась.
- Настроение: одна полоса из долей по настроениям, слева "отлично", насыщенность `colors.special` растет с настроением, под полосой легенда с числом дней. Сначала был точечный график по дням, но при пропусках и разбросе он ничего не говорил; список полосками дал бы три одинаковых блока подряд с топами.
- Топы: строка с подписью, полоской и числом, ширина полоски = число / число итогов (для срывов - / число срывов).
- Компания и срывы - текст и топы теми же строками.

Цвет графиков - `colors.special`: `sober` и `relapse` уже значат статус дня в календаре на том же экране. Фон дорожек - `colors.border`. Подписи вариантов - словарь `optionDict` (`option.hardship.*` и т.д.).

### Строки

Слайс `pages/progress/i18n.ts`: подпись "Последние 30 дней", заголовки блоков, плашка "соберем данные, N из 7", "ничего не отмечено", "N срывов" и "N вечеров, M без алкоголя" через `pluralize`, строки превью ("сильнее всего тянет в пятницу" - день недели в нужном падеже отдельным словарем `weekdayIn`, "тяги не было", "чаще всего помогает: ..."). ru и en рядом.

## Risks / Trade-offs

- [Среднее по 1-2 значениям на день недели шумное: при 7 итогах у каждого дня по одной точке] → это и есть "первая неделя", порог из спеки; больше данных - точнее. Подписей с числами не даем, чтобы не создавать ложной точности.
- [Пересечение "Последних 30 дней" и прошлого месяца] → подпись периода всегда видна над блоками.
- [Падеж дня недели в превью ("в пятницу", "во вторник")] → отдельный словарь из 7 готовых строк, без склонения кодом.

## Migration Plan

Миграций нет, нативных изменений нет: подхватывается dev-сервером, пересборка не нужна. Откат - удалить экран и секцию превью.
