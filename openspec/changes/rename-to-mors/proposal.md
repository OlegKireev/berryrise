# Proposal

## Why

В RuStore уже есть приложение "Решено" (бухгалтерский сервис), а слово "РЕШЕНО" зарегистрировано товарным знаком в классах 9 и 42 (свидетельство 864547, чужой правообладатель). Новое приложение с таким названием плохо ищется и рискует получить жалобу и снятие уже после публикации. Еще название не находится по запросу "трезв", а именно так ищут в RuStore. Менять название, id и иконку сейчас дешевле всего: приложение еще не опубликовано, а bundle id после публикации поменять нельзя.

## What Changes

- Русское название приложения - "Морс" (под иконкой и в интерфейсе). Заголовок в RuStore - "Морс: трезвая жизнь", дескриптор дает попадание в поиск по "трезв".
- Английское название - "Berryrise": в EN-строках вместо транслита "Resheno". Подпись под иконкой одна на все языки - "Морс", отдельное английское имя под иконкой не делаем.
- **BREAKING** bundle id и package: `dev.olegkireev.quit` -> `com.berryrise.app`. Для телефона это другое приложение: данные не переедут сами, переносим экспортом и импортом.
- slug и scheme: `resheno` -> `berryrise`. Проект на expo.dev переименовывается вручную, для нового package EAS генерирует новый ключ подписи.
- Имя файла базы `resheno.db` -> `berryrise.db`. Миграции не нужно: с новым package база все равно создается с нуля.
- Имя файла экспорта `resheno-...json` -> `berryrise-...json`, маркер в новых файлах - `com.berryrise.app`. Импорт временно принимает оба маркера, старый и новый, чтобы автор перенес свою историю.
- Новая иконка: ягода с бликом и хвостиком над горизонтом, линии отражения, почти черный фон с винным свечением за ягодой. Фон adaptive icon становится картинкой, потому что у него градиент. Медальон сплэша - с тем же фоном. Палитра интерфейса не меняется.
- "resheno" и "Решено" убираются отовсюду: `app.json`, `package.json` (имя пакета, пути `dist/*.apk`), i18n, `docs/idea.md`, README, CLAUDE.md, спеки, скилл `emulator-check`.

Вне рамок:

- Архив `openspec/changes/archive/` не трогаем: это история решений, в ней старое название уместно.
- Отдельная подпись под иконкой на английском (локализация `name`) - на этапе (c).
- Регистрация своих товарных знаков "Морс" и "Berryrise". До публикации нужна только проверка чужих знаков (ФИПС, USPTO, WIPO), это ручная задача автора.
- Карточка в RuStore (тексты, скриншоты) - отдельно, при публикации.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `app-theme`: новое требование про название приложения (под иконкой "Морс", в EN-интерфейсе "Berryrise"); сценарий иконки на рабочем столе описывает ягоду над горизонтом на темном фоне со свечением вместо солнца на шалфейном.
- `backup`: имя файла `berryrise-...json`, маркер `com.berryrise.app`, импорт принимает и старый маркер; сообщение про чужой файл называет "Морс".
- `onboarding`: в восстановлении из файла сообщение про чужой файл называет "Морс".

## Impact

- Нативное, одна пересборка dev build: `app.json` (`name`, `slug`, `scheme`, `android.package`, `ios.bundleIdentifier`, `adaptiveIcon.backgroundImage` вместо `backgroundColor`), PNG иконки и сплэша.
- Новый package на телефоне ставится рядом со старым, а не поверх. Старый удалить после переноса данных.
- EAS: переименовать проект на expo.dev в `berryrise` (иначе `eas build` упадет на несовпадении slug), новый keystore для `com.berryrise.app`.
- Код: `src/app/_layout.tsx` (имя базы), `src/features/backup/model/format.ts` и тест, i18n `backup`, `notifications`, `onboarding`.
- Ассеты: `assets/src/*.svg`, новый `android-icon-background.svg`, скрипт `yarn icons` в `package.json`.
- Документация и инструменты: `docs/idea.md`, README, CLAUDE.md, `.claude/skills/emulator-check/` (`SKILL.md`, `scripts/emu.py`: `PKG`, deeplink, путь базы), `yarn.lock` (имя workspace).
