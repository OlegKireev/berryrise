## MODIFIED Requirements

### Requirement: Экспорт в файл

Экспорт SHALL собирать все данные приложения в один JSON-файл и предлагать на выбор "Сохранить на телефон" или "Отправить". В файл MUST попадать все записи, включая мягко удаленные, и все настройки. Имя файла SHALL быть `berryrise-YYYY-MM-DD-HH-mm-SS.json` по локальному времени экспорта.

#### Scenario: Выбор способа

- **WHEN** пользователь нажал "Экспортировать"
- **THEN** видит варианты "Сохранить на телефон", "Отправить" и "Отмена"

#### Scenario: Удаленный срыв в файле

- **WHEN** пользователь удалил срыв и сделал экспорт
- **THEN** срыв есть в файле с отметкой удаления, после импорта этого файла он по-прежнему не показывается

### Requirement: Сохранение на телефон

"Сохранить на телефон" SHALL открывать системный диалог сохранения с подставленным именем файла и записывать файл туда, куда указал пользователь. В диалоге MUST быть доступны папка Download и корень памяти телефона. После записи пользователь SHALL видеть короткое уведомление "Сохранено" с именем файла, которое исчезает само. Если диалог закрыли без сохранения, ничего не происходит и сообщения об ошибке нет. Если записать не удалось, пользователь SHALL видеть сообщение об ошибке.

#### Scenario: Сохранение в Download

- **WHEN** пользователь 16 октября 2026 в 21:05:09 выбрал "Сохранить на телефон" и папку Download
- **THEN** в Download появляется `berryrise-2026-10-16-21-05-09.json`, приложение показывает "Сохранено"

#### Scenario: Сохранение в корень памяти

- **WHEN** пользователь выбрал "Сохранить на телефон" и в диалоге корень памяти телефона
- **THEN** файл экспорта появляется в корне памяти, приложение показывает "Сохранено"

#### Scenario: Диалог закрыт без сохранения

- **WHEN** пользователь закрыл диалог сохранения
- **THEN** файл не записан, сообщения об ошибке нет

### Requirement: Отправка файла

"Отправить" SHALL открывать системное меню "Поделиться" с файлом экспорта. Закрытие меню без выбора MUST NOT считаться ошибкой.

#### Scenario: Отправка

- **WHEN** пользователь 16 октября 2026 в 21:05:09 выбрал "Отправить"
- **THEN** открывается меню "Поделиться" с файлом `berryrise-2026-10-16-21-05-09.json`

#### Scenario: Отмена "Поделиться"

- **WHEN** пользователь закрыл меню "Поделиться", ничего не выбрав
- **THEN** данные в приложении не меняются, сообщения об ошибке нет

### Requirement: Формат файла

Файл SHALL содержать маркер приложения `com.berryrise.app`, версию схемы базы, момент экспорта и записи каждой таблицы как они есть в базе.

#### Scenario: Содержимое файла

- **WHEN** пользователь открыл экспортированный файл в текстовом редакторе
- **THEN** видит `"app": "com.berryrise.app"`, номер версии схемы, момент экспорта и записи по таблицам

### Requirement: Проверка файла

Система SHALL принимать только файл с маркером `com.berryrise.app`, версией схемы не новее своей и записями для каждой таблицы. Файлы приложения до переименования (маркер `dev.olegkireev.quit`) не принимаются: данные автора уже перенесены. Файл другой программы или не JSON SHALL отклоняться сообщением, что это не резервная копия приложения. Файл новее приложения SHALL отклоняться сообщением, что нужно обновить приложение. Отклоненный файл MUST NOT менять данные и MUST NOT доходить до подтверждения.

#### Scenario: Чужой файл

- **WHEN** пользователь выбрал фотографию или JSON другой программы
- **THEN** видит сообщение, что это не резервная копия "Морс", данные не меняются

#### Scenario: Файл из новой версии

- **WHEN** пользователь выбрал файл, сделанный в версии приложения с более новой схемой
- **THEN** видит сообщение "обнови приложение", данные не меняются

#### Scenario: Файл из старой версии

- **WHEN** пользователь выбрал файл, сделанный в версии приложения со старой схемой, и подтвердил
- **THEN** данные восстанавливаются и приводятся к текущей схеме
