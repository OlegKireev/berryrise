# Proposal

## Why

Счетчик дней сейчас виден только внутри приложения. Виджет на рабочем столе показывает стрик без открытия приложения и каждый раз напоминает о прогрессе. В `docs/idea.md` он запланирован (раздел "Виджет"), остальная база (стрик, темы, иконка) уже есть.

## What Changes

- Виджет 1x1 для Android: только число, текущий стрик, без подписи. Влезают минимум три цифры, кегль подбирается по количеству цифр.
- Светлая и темная тема по системе, цвета из токенов приложения.
- Тап по виджету открывает приложение.
- Виджет обновляется при запуске приложения, при уходе приложения в фон (это покрывает любые изменения данных) и сам раз в 30 минут (так новый день появится не позже чем через полчаса после полуночи).
- Для TalkBack у виджета есть описание с числом и словом "дней".
- Новая зависимость `react-native-android-widget` с config plugin: это нативное изменение, нужна пересборка dev build.

Вне скоупа:

- iOS-виджет.
- Другие размеры и другое содержимое: лучший стрик, "всего", сэкономлено, причина дня.
- Настройка виджета (выбор показателя, прозрачность фона).
- Точное обновление ровно в полночь (точных будильников в проекте нет).
- Свое действие по тапу, кроме открытия приложения (например, сразу на "Прогресс").

## Capabilities

### New Capabilities

- `home-widget`: виджет на рабочем столе Android с текущим стриком: содержимое, вид, обновление, тап.

### Modified Capabilities

Нет. Правило подсчета стрика не меняется, виджет берет его из `sobriety-streak`.

## Impact

- `package.json`, `app.json`: пакет `react-native-android-widget` и его плагин (виджет, размер, период обновления, превью, шрифт Manrope). Нативное изменение, пересборка dev build.
- Новая точка входа `index.ts`: регистрация обработчика виджета до `expo-router/entry`, поле `main` в `package.json`.
- Новый слайс `src/features/widget`: рисунок виджета, обновление из приложения и обработчик фоновых событий.
- Корневой layout: вызов обновления виджета при старте и уходе в фон.
- `assets/src/`: SVG превью виджета, `yarn icons` собирает из него PNG.
- `CLAUDE.md`, `docs/idea.md`: статус и описание виджета.
