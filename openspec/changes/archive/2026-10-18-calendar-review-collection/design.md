# Design

## Context

- `DayCircle` (`entities/habit/ui`) общий для календаря и полоски недели. Сейчас закраска считается по статусу (`relapse` или прошедший день со статусом), итоги - проп `dot`. Сегодня без срыва приходит со статусом `sober`, нейтральные дни - `null` (цвет `colors.border`).
- Календарь получает `reviewDates: Set<string>` из `useProgress`, полоска - флаг `reviewed` из `lastWeek`. Новых данных не нужно.
- `canReview(day, now)` из `entities/day-review` уже решает, можно ли заполнять день сейчас.
- В `pages/progress/ui` есть `Bar` (доля 0..1 на дорожке) и `Legend` с `ReviewDot`.

## Goals / Non-Goals

**Goals:**

- Одно правило отрисовки дня в `DayCircle`: цвет - статус, заливка - итоги.
- Счетчик и знак месяца из одной чистой функции с тестом.

**Non-Goals:**

- Анимация закраски дня после сохранения итогов.
- Хранить собранные месяцы: все считается, как стрик и достижения.

## Decisions

- **`DayCircle`: проп `reviewed` вместо `dot`.** `filled = reviewed`. Цвет `color(status)` - и для заливки, и для кольца (нейтральный - серый `colors.border`). Пунктир: `today && status !== 'relapse' && !reviewed`. Кольцо цвета статуса толще серого (1.5-2 против 1), чтобы пустой трезвый день не терялся; точное значение по скриншоту, константой. Текст на заливке - цвет фона (как сейчас), на кольце - `colors.text` у сегодняшнего и цветных, `colors.muted` у серых. Альтернатива - оставить точку и добавить кольцо - отвергнута: два сигнала об одном и том же.
- **Подсчет месяца - `monthReviews(year, month, start, now, reviewDates)` в `pages/progress/model/calendar.ts`.** Перебирает дни месяца `>= start`, `<= today` и `canReview(day, now)`, возвращает `{ done, total, collected }`, где `collected = total > 0 && done === total && месяц раньше текущего`. Тест в `calendar.test.ts`: утро и вечер, месяц старта, пропуск, текущий месяц заполнен без знака, `total = 0`. Лежит рядом с `monthWeeks`, потому что нужен только календарю.
- **Где показывается.** `Calendar` зовет `monthReviews` для открытого месяца. Знак - новый необязательный проп `mark` у `PeriodNav` (иконка рядом с подписью; модалка дня его не передает). Иконка - одна новая строка в мапе `Icon.tsx` (lucide, JS-only), выбор между `star`/`award`/`sparkles` по скриншоту. Под календарем перед легендой строка: `Bar` с долей `done / total` и подпись "N из M" или "месяц собран"; при `total = 0` строки нет. Строки в `progress/i18n.ts`, ru и en.
- **Легенда.** `ReviewDot` удаляется. Пункты: трезвый и срыв - закрашенные образцы, третий пункт - пара "кольцо / закрашен" с подписью вроде "итоги подведены" у закрашенного. Точная раскладка по скриншоту, без новых компонентов вне `Legend`.
- **Полоска недели** только передает `reviewed` в `DayCircle` вместо `dot`; `lastWeek` не меняется.

## Risks / Trade-offs

- [Закраска перестает значить "трезвый": пользователь, привыкший к зеленому, увидит кольца и подумает, что дни не засчитаны] → цвет кольца тот же зеленый, легенда объясняет; стрик и счетчик над полоской не меняются.
- [Старые пользователи без итогов увидят календарь из одних колец] → это и есть цель: видно, что можно собрать. Давления нет, счетчик спокойный.
- [Знак у текущего месяца появляется только 1-го следующего] → осознанно, иначе награду забирало бы каждое утро.

## Migration Plan

Схема базы не меняется. Нативных изменений нет: новая иконка lucide - JS.
