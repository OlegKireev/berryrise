# Proposal

## Why

Все данные лежат только в SQLite на телефоне. Android Auto Backup выручает не всегда: он может быть выключен, не переносит данные на iPhone и не позволяет откатиться к своей копии. Ручной экспорт и импорт в JSON через "Поделиться" описан в `docs/idea.md` как второй способ бэкапа, а `expo-sharing` и `expo-file-system` уже есть в сборке.

## What Changes

- В хабе настроек новая строка "Экспорт и импорт" перед "О приложении". Она открывает экран с двумя действиями.
- Экспорт: все таблицы базы, включая мягко удаленные строки и `settings`, записываются в файл `resheno-YYYY-MM-DD-HH-mm-SS.json`. Файл отдается в системное меню "Поделиться".
- Импорт: пользователь выбирает файл, подтверждает, и данные на телефоне целиком заменяются данными из файла. Замена идет одной транзакцией, при любой ошибке база остается как была.
- Файл принимается, только если он от этого приложения (`app: "dev.olegkireev.quit"`) и его версия схемы не новее, чем у приложения. Файл старой версии доводится до текущей обычными миграциями.
- После импорта уведомления перепланируются по настройкам из файла, уже показанные медали заново не празднуются.
- На первом шаге онбординга появляется тихая ссылка "Восстановить из файла". Если в файле есть старт, онбординг завершается, и открывается "Сегодня".
- `expo-file-system` становится прямой зависимостью, в той же версии, что уже стоит транзитивно через `expo`.
- Экспорт предлагает "Сохранить на телефон" (системный диалог "Сохранить как", можно выбрать Download и корень памяти) или "Отправить" ("Поделиться"). Для диалога сохранения добавляется `@react-native-documents/picker`. Это нативная зависимость, dev build нужно пересобрать.

Вне рамок:

- Слияние файла с данными на телефоне: импорт только заменяет.
- Автоматические и регулярные бэкапы, бэкап в облако из приложения.
- Шифрование файла и пароль на него.
- Экспорт в CSV и другие форматы для чтения человеком.
- Экстренные контакты как раздел. Таблица `contact` экспортируется как есть, сейчас она пустая.

## Capabilities

### New Capabilities

- `backup`: экспорт данных в файл и восстановление из файла, формат файла, проверка версии, атомарная замена.

### Modified Capabilities

- `settings`: в хабе новая строка "Экспорт и импорт".
- `onboarding`: онбординг можно завершить восстановлением из файла, на первом шаге ссылка "Восстановить из файла".
- `local-data`: данные могут покинуть устройство файлом, который пользователь сам экспортировал.

## Impact

- Новая фича `src/features/backup` (SQL по всем таблицам, чистый разбор файла с тестом, хуки экспорта и импорта, i18n).
- `src/shared/db`: восстановление базы до нужной версии схемы и вставка строк в одной транзакции рядом с `migrate`.
- `src/pages/settings`: новая страница и строка в хабе. Роут `src/app/settings/backup.tsx` и регистрация в корневом `Stack`.
- `src/pages/onboarding`: ссылка на `IntroPage`.
- `src/shared/ui/Icon.tsx`: новая иконка строки.
- `package.json`: прямая зависимость `expo-file-system`, новая нативная зависимость `@react-native-documents/picker` (пересборка).
- `CLAUDE.md`, `docs/idea.md` (статус).
