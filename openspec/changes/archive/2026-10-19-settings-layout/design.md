# Design

## Context

Хаб (`pages/settings/ui/SettingsPage.tsx`) - пять `Row` с `href` прямо в `Screen`, без своих данных. Дата старта и траты живут на `StartSpendingPage` на хуке `useSettings` (привычка, `maxStart`, `changeStart` без подтверждения). `Row` уже умеет показывать `children` справа и стрелку при `onPress`/`href`. `Card` - рамка с `padding: 16`, `gap: 8`. Медали на момент `now` считает `loadAchievements(db, now)` в `features/celebrate-achievement`, стрик - `streak()` из `entities/habit`. Число причин - активные строки `listReasons(db)`. Настройки уведомлений - `getPrefs`, запрет в системе - `permissionDenied` из `features/notifications`. Нативных изменений нет: новые иконки - JS из уже стоящего `lucide-react-native`.

## Goals / Non-Goals

**Goals:** один хук хаба отдает все значения строк и `changeStart`; решение о подтверждении - чистая функция с тестом; две маленькие общие обертки в `shared/ui` вместо повторения верстки на трех экранах.

**Non-Goals:** разделители между строками, новый вариант `Card`, перенос логики трат или уведомлений.

## Decisions

### Хук хаба - `useSettings`, на нем же экран трат

`useSettings` расширяется: на фокусе грузит привычку, срывы, `listReasons`, `getPrefs` и `permissionDenied` и отдает готовые значения (`startAt`, `maxStart`, `spending` - сумма и валюта или `null`, `reasonCount`, `notifications` - `{ on: number } | 'denied'`, `changeStart`). `SpendingPage` (бывшая `StartSpendingPage`) берет из него только `habit`. Отдельный хук ради одного `getHabit` не заводим: лишние запросы на экране трат дешевые, а второй хук дублировал бы загрузку.

Перечитывать на фокусе обязательно: значения в строках должны меняться после возврата из раздела (спека "Значения в строках хаба"). Подписка на `AppState` для запрета в системе остается только в `useNotificationSettings`: в хабе хватает фокуса, а если пользователь включил разрешение из шторки, не уходя с хаба, значение обновится при следующем фокусе.

### Подтверждение - чистая `model/startChange.ts`

`startChange(before, after)` принимает `{ current, got }` для старого и нового старта и возвращает `null` (подтверждать не надо) или `{ streak?: { from, to }, medalsLost: boolean }`. `streak` есть, только если `to < from`; `medalsLost` - есть ключ в `before.got`, которого нет в `after.got`. Тест рядом: сдвиг раньше - `null`, позже без срывов - стрик, позже при срывах (текущая серия не меняется, первая короче) - только медали.

Для нового старта `loadAchievements` получает необязательный `startAt` и подставляет его вместо `habit.startAt`. Это единственное изменение фичи; страница может ее импортировать (`pages` выше `features`). Стрик для текста берем из того же результата: добавить `current` в возвращаемый объект `loadAchievements`.

Альтернатива - сравнивать только `streak()` без медалей: проще, но при срывах текущий стрик от старта не зависит, и подтверждение не сработало бы ровно тогда, когда пропадают медали первой серии.

`Alert` с текстом и кнопками "Отмена"/"Изменить" рисует компонент строки (правило: `Alert` подтверждений - в `ui/`), хук отдает `checkStart(d) -> Promise<StartChange | null>` и `changeStart(d)`.

### Дата старта в строке

Сейчас Android-логика `DateTimeField` (открыть `DateTimePickerAndroid`, прижать к границам, обнулить время) спрятана внутри компонента. Выносим ее функцией `pickDate({ value, min, max, onChange })` в `shared/ui/DateTimeField.tsx` (там же, без нового файла) и зовем из `onPress` строки. На iOS `pickDate` не нужен: строка рисует справа сам `DateTimeField mode="date"` (компактный системный пикер), без `onPress`. Значение строки на Android - `formatDate(startAt)`.

Альтернатива - оставить экран старта с одним полем: лишний переход ради одного поля, решили убрать.

### Общие блоки в `shared/ui`

- `Group({ label, children })` - подпись `Text variant="label"` и `Card` с `gap: 0` и меньшим вертикальным отступом, внутри `Row`. Хаб и "О приложении".
- `Notice({ icon, children })` - `Card` с иконкой слева и содержимым (текст, кнопка). Дисклеймер в "О приложении" и плашка запрета на "Уведомлениях". Иконки: дисклеймер - `info`, запрет - новая `bellOff`.
- Значение строки - `Text variant="hint"` в `children` у `Row`; "выключены в системе" - `style` цвета `colors.relapse` (им же навигация красит уведомления). Отдельного пропа `value` у `Row` не вводим.
- Новая иконка `calendar` для строки "Дата старта".

### Роуты и строки

`app/settings/start.tsx` -> `app/settings/spending.tsx`, экран в корневом `Stack` переименовывается. Названия экранов в `shared/i18n/common.ts`: `startSpending` -> `spending` ("Траты"), `exportImport` -> `backup` ("Резервная копия"), плюс `startDate` ("Дата старта"). Подписи групп, значения строк и тексты подтверждения - в `pages/settings/i18n.ts`. `backupHint` делится на `exportHint` и `importHint`. Проверить, что `startSpending`/`exportImport` больше нигде не используются (онбординг берет свои строки).

## Risks / Trade-offs

- [Лишние запросы на экране трат через общий хук] → объем мизерный, при росте выделить хук.
- [Расчет медалей на каждый выбор более поздней даты] → один проход по истории, как на "Прогрессе", заметной задержки нет.
- [Значение "выключены в системе" в хабе не обновляется без смены фокуса] → принято, подробное состояние есть на экране уведомлений.
- [Медали, полученные после сдвига старта раньше, празднуются при следующем фокусе "Сегодня"] → это текущее поведение `celebrate-achievement`, не меняем.

## Migration Plan

Данные и схема не меняются. Старая ссылка `settings/start` нигде не сохраняется (нет диплинков на нее), переименование роута безопасно. Откат OTA возвращает старую верстку без последствий.
