# Spec Delta

## MODIFIED Requirements

### Requirement: Запись срыва

Модалка срыва SHALL требовать только время срыва, по умолчанию текущий момент. Время MUST быть не раньше начала дня старта и не позже текущего момента. Сохранение SHALL закрывать модалку, новая серия начинается с этого момента.

#### Scenario: Срыв сейчас

- **WHEN** пользователь открыл модалку и сразу сохранил
- **THEN** срыв записан с текущим временем, модалка закрыта

#### Scenario: Срыв вчера вечером

- **WHEN** пользователь выбрал вчерашнюю дату и 21:00 и сохранил
- **THEN** срыв записан на вчера 21:00, вчерашний день не трезвый

#### Scenario: Срыв в день старта

- **WHEN** днем старта указан сегодняшний день, пользователь выбрал сегодня 08:00 и сохранил
- **THEN** срыв записан, стрик по-прежнему 0 дней

#### Scenario: Время вне допустимого

- **WHEN** пользователь пытается выбрать время раньше дня старта или в будущем
- **THEN** выбрать его нельзя

#### Scenario: Отмена

- **WHEN** пользователь закрыл модалку без сохранения
- **THEN** срыв не записан
