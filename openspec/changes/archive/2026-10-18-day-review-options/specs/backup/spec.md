# Spec Delta

## MODIFIED Requirements

### Requirement: Импорт атомарный

Замена данных при импорте SHALL выполняться целиком или никак. Перед завершением импорта система SHALL проверить записи файла, приведенные к текущей схеме, теми же правилами, что и при чтении: запись с недопустимым значением в обязательном поле делает файл поврежденным. Если файл не удалось применить, данные на устройстве MUST остаться такими, какими были до импорта, и пользователь SHALL увидеть сообщение, что файл поврежден.

#### Scenario: Файл с испорченной записью

- **WHEN** в файле у одной записи итогов дня нет обязательного поля, пользователь подтвердил импорт
- **THEN** появляется сообщение "файл поврежден", все прежние данные на месте

#### Scenario: Значение не того типа

- **WHEN** в файле у срыва вместо момента срыва текст, пользователь подтвердил импорт
- **THEN** появляется сообщение "файл поврежден", все прежние данные на месте

#### Scenario: Устаревший вариант в файле

- **WHEN** в файле у срыва среди мест есть место, которого нет в текущем списке, пользователь подтвердил импорт
- **THEN** данные восстанавливаются, неизвестное место не показывается
