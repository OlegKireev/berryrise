# Spec Delta

## MODIFIED Requirements

### Requirement: О приложении

Экран "О приложении" SHALL показывать название и версию приложения и дисклеймер о том, что приложение не заменяет врача, тем же текстом, что в онбординге. Если приложение работает на скачанном обновлении, рядом с версией SHALL быть короткий id обновления и дата его публикации. На встроенном в APK бандле строка версии остается без обновления. Ниже SHALL быть строка "Проверить обновления" (ручная проверка из требований `app-updates`; на время проверки подпись строки "Проверяю…", и повторный тап ничего не делает; в сборке без OTA строки нет) и строка "Журнал", которая открывает экран журнала (требования `error-log`).

#### Scenario: Открытие

- **WHEN** пользователь открыл "О приложении"
- **THEN** видит версию приложения и текст "Приложение не заменяет врача..."

#### Scenario: Работает обновление

- **WHEN** приложение запущено на обновлении, опубликованном 19 октября
- **THEN** рядом с версией видны первые символы id обновления и дата "19 октября"

#### Scenario: Встроенный бандл

- **WHEN** приложение запущено на бандле из APK
- **THEN** видна только версия приложения

#### Scenario: Проверка обновлений

- **WHEN** пользователь нажал "Проверить обновления", и новых бандлов нет
- **THEN** появляется тост "Установлена последняя версия", пользователь остается на экране

#### Scenario: Повторный тап во время проверки

- **WHEN** проверка уже идет, и пользователь снова нажал строку
- **THEN** вторая проверка не запускается

#### Scenario: Журнал

- **WHEN** пользователь на экране "О приложении" нажал "Журнал"
- **THEN** открывается экран журнала, "назад" возвращает в "О приложении"
