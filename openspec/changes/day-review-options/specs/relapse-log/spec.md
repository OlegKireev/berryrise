# Spec Delta

## MODIFIED Requirements

### Requirement: Необязательный разбор срыва

Модалка SHALL предлагать необязательный разбор: настроение (одно из 5), места (несколько), трудности (несколько) и заметку. Места SHALL быть по порядку: дома, на работе, в гостях, в баре или ресторане, в дороге, на улице. Трудности MUST быть готовыми, общими с итогами дня. Варианта "ничего" MUST NOT быть. Любое поле можно оставить пустым.

#### Scenario: Без разбора

- **WHEN** пользователь сохранил срыв, ничего не выбрав
- **THEN** срыв записан только со временем

#### Scenario: С разбором

- **WHEN** пользователь выбрал настроение, места "в гостях" и "в баре или ресторане", трудность "рядом пили" и сохранил
- **THEN** срыв записан с этими значениями

#### Scenario: Список мест

- **WHEN** пользователь открыл модалку срыва
- **THEN** в местах шесть вариантов от "дома" до "на улице", без "в компании" и "с семьей"
